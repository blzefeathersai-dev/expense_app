# How to Build Your Expense Tracker Android App 📱

## 1. Prerequisites
- **Download Android Studio**: [Click here to download](https://developer.android.com/studio).
- Install it using the default settings.

## 2. Open the Project
1. Launch **Android Studio**.
2. Click **Open**.
3. Select this folder:
   `C:\Users\Sahil\OneDrive\Desktop\expense_app\android`
   *(Make sure to select the `android` folder, NOT the main folder)*.
4. Click **OK**.

## 3. Build the APK
1. Wait for "Sync" to finish.
2. Go to **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)** in the top menu.
3. Once done, click **locate** in the popup to find your file.
4. Send it to your phone and install! 🚀
